# 立て札カードジェネレーター (Tatefuda Generator)

花屋（着生屋）様向けの、贈答用立て札カードを生成するWebアプリケーションです。
高級感のあるデザインで、A4・A4半分（A5）サイズの印刷用高解像度PNG画像を生成できます。

## 特徴
- **インストール不要・ビルド不要**: ブラウザで `index.html` を開くだけですぐに使用できます。
- **高解像度書き出し**: 印刷を想定し、300dpi（A4: 2480×3508px, A5: 1748×2480px）で画像を生成します。
- **リアルタイムプレビュー**: 入力した内容が即座に右側のプレビューに反映されます。
- **選べる装飾フレーム**: アイビー（蔦）、オリーブ、シンプルゴールドの3種類のフレームデザインから選択可能。

## 使い方
1. 本フォルダ内の `index.html` を、Google Chrome, Safari, Edge などのモダンブラウザで開きます。
2. 画面左側のフォームから以下の項目を設定します。
   - 用紙サイズ（A4大 / A4半分小）
   - 向き（縦 / 横）
   - 装飾フレームデザイン
   - お届け先（任意）
   - タイトル（「祝開店」などから選択、または自由に手入力）
   - 差出人の会社名、役職（任意）、氏名（必須）
3. 右側のプレビューで仕上がりを確認します。
4. 「PNGとしてダウンロード (300dpi)」ボタンをクリックして、画像を保存します。

## カスタマイズ（装飾フレームの差し替え）
コード（`app.js`）内のコメント `// ※デザイン案1：アイビー風装飾` などの部分で、SVGパスデータを直接定義しています。
より本格的な商用ベクター素材（SVG）を入手した場合は、この `SVG_FRAME_IVY` などの変数内の文字列を、新しいSVGコードに置き換えることで簡単にデザインを差し替えることができます。
SVGコードは、`viewBox` 属性を持ち、`preserveAspectRatio="none"` を指定することで、縦横のサイズ変更に柔軟に対応させることができます。

## 技術仕様
- **HTML5 / CSS3 / Vanilla JavaScript**: 依存ライブラリなしで軽量・高速に動作します。
- **Canvas API**: 高解像度でのテキストレンダリングと画像合成を行います。
- **SVG Data URI**: クロスオリジン制約（CORS）を回避し、ローカル環境（`file://`）でも画像ダウンロード機能が動作するように、SVGデータをJavaScript内でBase64エンコードしてキャンバスに描画しています。
- **Google Fonts (Noto Serif JP)**: 立て札に相応しい、品のある明朝体を使用しています。
